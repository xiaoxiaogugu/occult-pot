# 新月岛撒娇罐

多区循环找罐、打罐、挖箱。卫月自定义插件库。

## 安装

1. 卫月 → **设置** → **实验性功能** → **自定义插件仓库**
2. 添加：

```
https://raw.githubusercontent.com/xiaoxiaogugu/occult-pot/main/pluginmaster.json
```

3. `/xlplugins` → 搜索「新月岛撒娇罐」→ 安装

命令：`/ocpot`，`/ocpot start` / `stop` / `skip` / `dig`

## 依赖

需要 Daily Routines（进岛、跨界、退本、小水晶）、vnavmesh 与自动战斗。绿玩挖箱用 vnav；取消则用 xsz 潜水 TP。
